# 🤝 Handoff

## Before handoff

- [ ] all P1/P2 incidents have an owner
- [ ] open alerts are acknowledged or linked
- [ ] backup age is under 48h
- [ ] disk is above 15% free
- [ ] Prometheus targets are up
- [ ] the last deploy manifest matches `dashboards/devops`
- [ ] pending changes are listed

## Handoff note

```md
## Handoff YYYY-MM-DD

- Open incidents:
- Open alerts:
- Backup age:
- Disk free:
- Deploy commit:
- Risks:
- Next actions:
```

## After handoff

The incoming owner reads this note and the last postmortem before changing
anything.
